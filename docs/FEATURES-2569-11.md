# ฟีเจอร์ใหม่ (พฤศจิกายน 2569)

อัปเดตได้จากเมนู **อัปเดตระบบ** (ระบบจะติดตั้งไลบรารีใหม่ให้เองตอน build)

## 1. 🧪 ทดสอบปุ่มประจำเดือน (เมนู "ทดสอบปุ่ม")
- ผู้ป่วยหรือ อสม. **กดปุ่มสั้น ๆ 3 ครั้ง** แล้วไฟเขียวขึ้น แปลว่าผ่าน ระบบบันทึกเป็นการทดสอบ ไม่ใช่เหตุจริง และไม่มีใครถูกเรียก
- หน้า "ทดสอบปุ่ม" แสดงว่าเดือนนี้ปุ่มไหนทดสอบแล้ว ปุ่มไหนยังไม่ทดสอบ พร้อมแบตเตอรี่และความแรงสัญญาณ ดูย้อนหลังรายเดือนได้
- **LINE เตือนอัตโนมัติ** ส่งถึง อสม. ลำดับแรกของผู้ป่วยแต่ละราย พร้อมรายชื่อปุ่มที่ยังไม่ทดสอบ
  - ค่าเริ่มต้น: วันที่ 1 และวันที่ 15 เวลา 10:00 น. ปรับได้ในหน้านั้น
  - ถ้าเซิร์ฟเวอร์ปิดอยู่ในวันนั้น จะส่งย้อนหลังได้ไม่เกิน 3 วัน
- ส่ง LINE ยืนยันให้ อสม. ทุกครั้งที่ปุ่มทดสอบผ่าน (ปิดได้)
- มีปุ่ม "ส่ง LINE เตือนตอนนี้" สำหรับส่งเองนอกรอบ

## 2. 🗺️ แผนที่
- **หมุดบ้านผู้ป่วยแบ่งตามสี**: 🔴 มีเคสรอรับเรื่อง (กะพริบ) · 🟠 กำลังดูแล / แบตต่ำ / ไฟดับ · 🟢 ปกติ · ⚪ ปุ่มออฟไลน์ · 🔵 ยังไม่มีปุ่ม
- **เกตเวย์** แสดงพร้อมวงรัศมีสัญญาณ (ค่าเริ่มต้น 3 กม. ตั้งได้ที่ `geo.coverage_m`) ถ้าเกตเวย์ออฟไลน์ วงจะเป็นเส้นประสีแดง
- **คลิกหมุด** เพื่อโทร เปิดเคส หรือนำทางด้วย Google Maps
- **ปักหมุดบ้าน**: เลือกชื่อผู้ป่วยที่ยังไม่มีพิกัด แล้วคลิกบนแผนที่ตรงบ้าน
- ผู้ใช้สิทธิ์ "ดูอย่างเดียว" เห็นเฉพาะเกตเวย์ เพราะตำแหน่งบ้านเป็นข้อมูลส่วนบุคคล
- ภาพแผนที่มาจาก OpenStreetMap ข้อมูลผู้ป่วยไม่ถูกส่งออกไปภายนอก

## 3. 📲 ติดตั้งเป็นแอป + แจ้งเตือนบนมือถือ (ไปที่ "บัญชี")
- **ติดตั้งแอป**:
  - Android/Chrome: เปิดเมนู ⋮ แล้วเลือก "ติดตั้งแอป"
  - iPhone: เปิดใน Safari กดปุ่มแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม"
- **เปิดการแจ้งเตือน**: กด "🔔 เปิดการแจ้งเตือนบนอุปกรณ์นี้" แล้วกด "ส่งทดสอบ"
  - จะเด้งเตือนเมื่อมีเหตุใหม่ เมื่อยังไม่มีผู้รับเรื่องเกินเวลา และเมื่อเกตเวย์ขาดการเชื่อมต่อ
  - แตะการแจ้งเตือนแล้วเปิดเคสนั้นทันที
  - เป็นช่องทาง**เสริม** LINE ไม่ได้แทน LINE
  - ส่งเฉพาะผู้ดูแลระบบและเจ้าหน้าที่
  - ข้อความเป็นไปตามระดับความเป็นส่วนตัวของ LINE (ถ้าตั้งเป็น minimal จะเห็นแค่ชื่อหมู่บ้าน)
- iPhone ต้อง**ติดตั้งเป็นแอปก่อน** (iOS 16.4 ขึ้นไป) จึงจะเปิดการแจ้งเตือนได้
- ต้องเข้าผ่าน **https://** เท่านั้น

## 4. 📄 รายงาน PDF ประจำเดือน (เมนู "รายงาน" → "รายงาน PDF")
- ขนาด A4 ใช้ฟอนต์สารบรรณ (Sarabun) วันที่เป็น พ.ศ.
- **เนื้อหา**: สรุปภาพรวม, กราฟรายชั่วโมงและรายวัน, แยกตามหมู่บ้าน, ผลทดสอบปุ่ม, สถานะอุปกรณ์และเกตเวย์, รายการเหตุทั้งหมด และช่องลงนาม 2 ท่าน
- **หัวรายงาน** ตั้งที่ ตั้งค่า → 🏥 หน่วยงาน: ชื่อ รพ.สต. / อบต., ผู้รายงาน, ผู้อนุมัติ และโลโก้ซ้าย/ขวา (PNG/JPG ไม่เกิน 400 KB)
- ผู้ใช้สิทธิ์ "ดูอย่างเดียว" ได้รายงานแบบไม่มีชื่อผู้ป่วย

## 5. 🔐 ยืนยันตัวตน 2 ขั้น (ค่าเริ่มต้น: ปิด)
- **เปิดบังคับใช้** ที่ ตั้งค่า → 🔐 ความปลอดภัยการเข้าสู่ระบบ
  - บังคับผู้ดูแลระบบเสมอ และเลือกเพิ่มเจ้าหน้าที่หรือผู้ดูอย่างเดียวได้
  - ผู้ใช้ที่ยังไม่ได้ตั้งค่าจะต้องสแกน QR ด้วย Google หรือ Microsoft Authenticator ก่อนใช้งานต่อ
- **เปิดใช้เอง** ได้ที่ "บัญชี" แม้นโยบายจะปิดอยู่
- **รหัสสำรอง** 10 ชุด แต่ละชุดใช้ได้ครั้งเดียว ใช้แทนรหัสจากแอปเมื่อมือถือหาย สร้างชุดใหม่ได้ที่ "บัญชี"
- รหัสผิดนับรวมกับรหัสผ่านผิด ผิด 5 ครั้งล็อกบัญชี 15 นาที และรหัสที่ใช้ไปแล้วใช้ซ้ำไม่ได้
- **มือถือหาย**: ผู้ดูแลระบบอีกคนไปที่หน้าผู้ใช้แล้วกด "รีเซ็ต 2FA"
- **ผู้ดูแลระบบทุกคนเข้าไม่ได้**: ใช้คำสั่งบนเซิร์ฟเวอร์
  ```bash
  cd /opt/sos/infra && sudo docker compose exec backend python -m app.cli reset-2fa <username>
  ```

## อื่น ๆ
- แก้ปัญหาหน้าเว็บว่างเปล่าเมื่อกดรีเฟรชขณะล็อกอินอยู่
- รหัส 2FA ที่ผิดไม่ทำให้หลุดออกจากระบบอีกต่อไป
- หลังออกจากระบบ เข้าใหม่จะกลับไปที่หน้าแรก
