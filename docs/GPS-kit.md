# ชุด GPS (เตรียมไว้สำหรับอนาคต)

สถานะ: **ฝั่งเซิร์ฟเวอร์/แดชบอร์ดพร้อมใช้และทดสอบแล้ว** · **เฟิร์มแวร์ GPS ยังไม่เคยคอมไพล์/ต่อกับโมดูลจริง** (พาร์เซอร์ NMEA และตัวเข้ารหัสทดสอบบนเครื่องเทียบกับตัวเข้ารหัสของ backend แล้ว) · ไม่ต้องมี GPS ระบบก็ทำงานเต็มที่เหมือนเดิม

## ได้อะไร
| ส่วน | ใช้ทำอะไร |
|---|---|
| GPS ที่อุปกรณ์ผู้ป่วย (ทางเลือก) | ส่งตำแหน่งตามหลังการแจ้งเหตุ → LINE ส่งตำแหน่งให้คนที่ถูกแจ้งแล้ว, หน้าเคสแสดงแผนที่ + ห่างจากบ้านเท่าไร, เตือนถ้าอุปกรณ์อยู่ห่างบ้านเกิน 150 ม. (ตั้งได้) เช่น ถูกย้ายไปที่อื่น |
| GPS ที่เกตเวย์ (ทางเลือก) | เทียบกับตำแหน่งที่ลงทะเบียนไว้ ถ้าห่างเกิน 200 ม. (ตั้งได้) เตือนว่าเกตเวย์อาจถูกย้าย/ขโมย |
| ตำแหน่งที่ลงทะเบียนเอง | ไม่ต้องมีฮาร์ดแวร์ GPS ก็ใส่พิกัดเกตเวย์เองในหน้า "เกตเวย์" ได้ |

## ข้อจำกัดที่ต้องรู้
- GPS **ในอาคารอ่านยาก** (หลังคา/ผนังบัง): ปกติได้ตำแหน่งช้าหรือไม่ได้ และคลาดเคลื่อนหลายสิบเมตร — ใช้เป็นแนวทางประกอบ ไม่ใช่ตำแหน่งแน่นอน; ระบบไม่ใช้ตำแหน่งที่ดาวเทียม < 4 ดวง
- อุปกรณ์ส่งตำแหน่งหลัง L1 ACK เท่านั้น (ไม่ทำให้การแจ้งเหตุช้าลง) ไม่เก็บเส้นทาง เก็บเฉพาะตำแหน่งล่าสุด
- ตำแหน่งผู้ป่วยเป็นข้อมูลอ่อนไหว (ดู `PDPA.md`) — ใส่ในหนังสือยินยอมด้วยถ้าใช้ GPS
- ความละเอียดการเข้ารหัส ≈ 1.2 ม. (เหนือ-ใต้) / 2.3 ม. (ตะวันออก-ตะวันตก) เกินพอสำหรับการใช้งานนี้

## ฮาร์ดแวร์ที่แนะนำ (ต้องตรวจสอบเองก่อนซื้อ)
**อุปกรณ์ผู้ป่วย:** โมดูล GPS 3.3 V แบบ UART NMEA 9600 เช่น ATGM336H หรือ NEO-6M (+ เสาเซรามิก/แอคทีฟ) · ต่อ TX ของ GPS → GPIO33, RX ของ GPS → GPIO34, VCC → 3V3, GND · **ตรวจก่อนว่าบอร์ด Heltec V3 รุ่นของคุณมีขา GPIO33/34 ออกที่แถวขา** ถ้าไม่มี แก้ `PIN_GPS_RX/TX` ใน `firmware/include/config.h`
**เกตเวย์:** ไม่ยืนยันว่า HAT WM1302 ที่ซื้อมีโมดูล GPS มาด้วยหรือไม่ — ดูที่ตัวบอร์ด/ใบสเปกของรุ่นที่ได้รับ ถ้าไม่มี ใช้ GPS แบบ USB (u-blox) เสียบ Pi แล้วติดตั้ง `gpsd`:
```bash
sudo apt install gpsd gpsd-clients
sudo systemctl enable --now gpsd     # ชี้ DEVICES ใน /etc/default/gpsd เป็น /dev/ttyACM0 (หรือ /dev/ttyAMA0 ถ้าต่อ UART)
gpspipe -w -n 5                      # ดูว่าได้ TPV mode 2/3 และ satellites
```
สคริปต์ `sos-gateway-report` จะอ่านจาก gpsd อัตโนมัติถ้ามี `gpspipe` และส่งตำแหน่งไปกับรายงานทุกนาที (ถ้าไม่มี gpsd ก็ข้ามเงียบ ๆ)

## เปิดใช้งานเฟิร์มแวร์ GPS
```bash
cd firmware
g++ -std=c++17 -Wall -Wextra -o /tmp/test_gps test/test_gps.cpp && /tmp/test_gps   # ต้องขึ้น ALL OK
pio run -e heltec_v3_gps          # บิลด์ด้วย -D SOS_GPS=1
```
ทดสอบฝั่งเซิร์ฟเวอร์โดยไม่ต้องมีฮาร์ดแวร์: `python simulator/sim.py ... loc --lat 13.9115 --lon 100.5954 --sats 8 --hdop 1.2`

## สัญญา LOC (FPort 4, 9 ไบต์, uplink แบบ unconfirmed)
`[0x18, alert_id, lat24(3B BE), lon24(3B BE), sats<<4 | hdop×2]` · lat24 = ⌊(lat+90)/180·2²⁴ + ½⌋ · lon24 = ⌊(lon+180)/360·2²⁴ + ½⌋ · sats สูงสุด 15 · hdop×2 สูงสุด 15 (=7.5)
ตัวอย่าง: `encode_loc(5, 13.9115, 100.5954, 8, 1.2)` = `180593c906c788d582` · ชุดทดสอบที่ใช้ร่วมกันระหว่าง Python กับ C++: `firmware/test/loc_vectors.inc`
